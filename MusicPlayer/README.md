# Музыкальный плеер с поддержкой вложенных плейлистов

**Вариант 7. Паттерны проектирования (Composite, Iterator)**

## Описание задания
Консольное приложение, имитирующее музыкальный плеер. Плеер проигрывает треки и плейлисты. Главная особенность: плейлисты могут содержать другие плейлисты (вложенность). Приложение должно единообразно перебирать всё содержимое (включая вложенные плейлисты), показывать текущий трек и уметь считать общую длительность.

## Использованные паттерны

### 1. Composite (Компоновщик)
**Проблема:** Треки и плейлисты — разные сущности, но нам нужно обращаться с ними одинаково (например, чтобы посчитать общую длительность всего дерева).
**Решение:** Создан общий интерфейс `IPlayable`. Класс `TrackItem` (лист) и `Playlist` (узел) реализуют этот интерфейс. Плейлист содержит список `List<IPlayable>`, поэтому метод `GetDuration()` рекурсивно вызывает сам себя для вложенных элементов.

### 2. Iterator (Итератор)
**Проблема:** Нужно обойти дерево треков «сверху вниз», не заботясь о том, на каком уровне вложенности они находятся. Писать сложные рекурсивные циклы прямо в `Main` — плохая идея.
**Решение:** Создан интерфейс `IPlaylistIterator` и класс `DepthFirstIterator`. Итератор использует стек (`Stack`), чтобы «заныривать» внутрь вложенных плейлистов и доставать треки по одному. Клиентский код просто вызывает `HasNext()` и `Next()`.
